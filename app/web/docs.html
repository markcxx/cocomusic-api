入门指南

本服务提供 COCO 音乐解析 API 与一个可直接使用的调试台页面，可用于快速验证接口返回与播放效果。

功能概览
- 歌曲解析：通过平台与歌曲 ID 获取播放直链、封面、歌词链接、官方页链接等元信息 - 调试台：在网页中直接请求 /v1/music/play-info，并在页面内试听 - 鉴权：当前版本未启用
页面入口
首页: {BASE_URL}/ 文档: {BASE_URL}/docs 调试台: {BASE_URL}/playground
快速请求
curl -X POST "{BASE_URL}/v1/music/play-info" -H "Content-Type: application/json" -d "{\"platform\":\"kugou\",\"id\":\"E5715D67DB3B804F127C3CD9198F2F22\"}"
POST

歌曲解析

通过歌曲 ID 与平台类型解析出可播放的音频直链，并返回歌曲元信息（封面、官方页链接、歌词链接等）。

请求端点

/v1/music/play-info

请求体 (JSON)

参数名 类型 描述
platform string 平台类型：qq / kugou / kuwo。
* 必填项
id string 歌曲 ID（例如酷狗 hash）。
* 必填项

响应 data 字段

参数名 类型 描述
url string 重定向后的最终播放直链。
link string 平台官方播放页链接（如酷狗 song hash 页）。
cover string 封面图最终 URL（重定向后）。
lrc string 歌词接口 URL。
name / artist / album string 歌曲元信息。
songid string 歌曲 ID（通常等于入参 id）。
type string 音频扩展名（如 mp3）。
platform string 平台类型。

接口鉴权

当前版本未启用鉴权。后续接入 API Key 时，本节将补充请求头与错误码说明。
